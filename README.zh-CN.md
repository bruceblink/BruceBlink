## 关于我

我的工作横跨后端工程与系统软件。目前工作主要使用 **Go**，并以 **Rust、Go 和 Elixir** 作为核心发展方向。我关注如何跨语言、跨平台设计、构建、运行和持续演进可靠的软件。

我的项目涉及身份基础设施、分布式系统、网络、点对点软件和原生桌面应用。我重视清晰的边界、可观察的行为，以及解决实际问题的工程设计。
